### Scope of reported findings

- The Ada-CISA accuracy figures are seeded CPU reference simulation results with 50–60 trials per condition, not model-level retrieval benchmarks.
- The 1M-token read count is an analytical traffic-model estimate; the 10.47× latency number is a heuristic model output, not GPU timing.
- The formal proof suite checks selected algebraic implications. It does not prove empirical rates or hardware behavior. See [Lean-checked claims](./formal/FORMAL_VERIFICATION.md).

The ACDG source paper was selected from the 2026-11-05 daily index after an audit found no ACDG/SLA source citation or paper-specific artifact in the repository history. The daily index contained only title/abstract metadata; the full arXiv HTML was consulted for this extension. The CPU study and Lean lemma do not verify accelerator performance or model-level quality.

The NanoKV source was selected from the 2026-11-05 daily index after checking the existing paper index and Git history for its arXiv identifier; no prior NanoKV extension or citation was present. The full arXiv HTML was consulted for this extension. Its CPU results are synthetic attention-reference measurements and do not establish NanoKV video quality or accelerator performance.
